# Blabbej
A simple GUI client for [Blabber](https://github.com/megahomyak/chatfiles).

### Running
For now, you have to set server address and credentials using environment variables: `BLABBER_SERVER`, `BLABBER_CREDS`.
Optionally you can use `BLABBER_ROOM` to override default room name `general`.
```shell
$ gradlew run
```
